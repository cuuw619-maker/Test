# WALLORA

Статическая галерея обоев, аватарок и случайных открытий из Википедии.

## Источники изображений

Каталог объединяет несколько независимых открытых источников:

- **Wikimedia Commons** — фотографии, иллюстрации и медиафайлы.
- **Openverse** — поиск изображений с Creative Commons и другими открытыми лицензиями.
- **Art Institute of Chicago** — произведения из Open Access коллекции, отбираются только файлы, отмеченные как Public Domain.
- **NASA Image and Video Library** — дополнительная подборка изображений для космических тем.

Результаты объединяются в одной сетке. Для каждого изображения показываются источник, автор и доступные сведения о лицензии. Ссылки ведут на оригинал и страницу с условиями использования. Доступность и количество результатов зависят от конкретного запроса и доступности внешних API.

## Разделы

- **Обои:** аниме, минимализм, игры, киберпанк, тёмная эстетика, автомобили, космос, природа и абстракция.
- **Аватарки:** аниме, пиксель-арт, минимализм, фэнтези, животные и абстрактные иллюстрации.
- **Факты:** случайная статья из русской Википедии, краткое вступление, изображение при наличии и ссылка на оригинал.

## Интерфейс

- Поиск и подгрузка следующих страниц из доступных источников.
- Фильтр ориентации и сортировка по разрешению, названию или случайному порядку.
- Просмотр изображения, автора, источника и лицензии.
- Избранное хранится в localStorage.
- Тёмная, светлая и системная темы.
- Настройки частиц, анимаций и 3D-наклона карточек.
- Адаптация для телефонов, планшетов и ПК.

## Технологии и хранение

Только HTML, CSS и JavaScript. Нет backend, собственной базы данных, платных API, ключей, сборщика или установки зависимостей. Статьи загружаются через публичный API русской Википедии. Избранное и настройки хранятся только в текущем браузере и не синхронизируются между устройствами.

## Публикация на GitHub Pages

1. Открой Settings → Pages в репозитории.
2. В Build and deployment выбери Deploy from a branch.
3. Выбери ветку main и папку /(root), затем нажми Save.
4. Дождись завершения публикации GitHub Pages.

## Важно о лицензиях

Openverse и Wikimedia содержат файлы с разными лицензиями. Для работ Art Institute отображаются только произведения, помеченные музеем как Public Domain. Для материалов NASA нужно проверять условия конкретного файла: не каждый материал на сайте NASA обязательно свободен от сторонних прав. Перед повторным использованием всегда открывай страницу оригинала.

## Ограничения

Для каталога и случайных статей требуется подключение к интернету. Внешние источники могут менять доступность, структуру API или ограничения запросов. Если один провайдер временно недоступен, сайт старается показать результаты остальных. Локальные настройки и избранное не синхронизируются.
