# MULTITOOL

Адаптивный статический сайт с играми, рулеткой и погодой.

- Рулетка с редактируемыми вариантами, цветами и весами выпадения.
- Крестики-нолики против компьютера (minimax) и на двоих.
- Змейка с клавиатурным и сенсорным управлением.
- 2048 с управлением стрелками и свайпами.
- Найди пары — карточная игра на память.
- Тест реакции с личным рекордом.
- Погода: поиск городов, геолокация, карта мира и ручной ввод координат.
- Open-Meteo + wttr.in; карта использует резервные тайловые источники CARTO и OpenStreetMap.
- Погодные частицы, звуки, темы, адаптивный интерфейс.

Статический проект на HTML/CSS/JS, без backend и платных API-ключей. Погода, геокодирование и карта требуют интернета. Геолокация работает через HTTPS/localhost. Если провайдер карты блокируется, введи координаты вручную или открой OpenStreetMap.
