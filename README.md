# WALLORA

Статическая галерея обоев для GitHub Pages. Проект работает на обычных HTML, CSS и JavaScript — без сервера, базы данных, регистрации и ключей API.

## Возможности

- Поиск изображений в Wikimedia Commons.
- Категории: природа, космос, архитектура, автомобили, океан, минимализм и животные.
- Фильтрация по ориентации и сортировка загруженных изображений.
- Просмотр оригинала, размера, автора и сведений о лицензии.
- Избранное хранится локально в браузере через localStorage.
- Адаптивная верстка для телефонов, планшетов и компьютеров.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. После публикации адрес сайта появится в этом же разделе.

## Источник изображений

Поиск выполняется через публичный API [Wikimedia Commons](https://commons.wikimedia.org/). Картинки загружаются с серверов Wikimedia; оригинал и страница файла доступны из окна просмотра. Условия лицензии отличаются у разных файлов — перед повторным использованием изображения проверяйте лицензию и требования к атрибуции на странице конкретного файла.

## Хранение данных

Собственная база данных не используется. Избранное сохраняется только в браузере и на устройстве, где сайт открыт. Оно не синхронизируется между устройствами и браузерами.

## Локальный запуск

Откройте index.html в браузере или запустите любой локальный статический HTTP-сервер. Для загрузки каталога потребуется подключение к интернету.
