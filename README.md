# WALLORA

Многостраничное по смыслу, но полностью статическое веб-приложение: обои, аватарки и случайные статьи Википедии в одном интерфейсе.

## Что внутри

- **Обои:** подборки по аниме, минимализму, играм, киберпанку, тёмной эстетике, автомобилям, космосу, природе и абстракции.
- **Аватарки:** иллюстрации и портреты в аниме, пиксельном, минималистичном и других стилях.
- **Факты:** случайная статья из русской Википедии с кратким вступлением, изображением (если есть) и ссылкой на оригинал.
- Поиск по Wikimedia Commons, постраничная загрузка, фильтрация формата и сортировка.
- Просмотр оригинала, размера, автора и сведений о лицензии.
- Избранное сохраняется локально.
- Тёмная, светлая и системная темы.
- Настройки частиц, анимации и 3D-наклона карточек.
- Адаптивный интерфейс для мобильных устройств и ПК.

## Стек и хранение

Только HTML, CSS и JavaScript. Нет backend, базы данных, платных API, ключей, сборщика или установки зависимостей. Изображения загружаются из Wikimedia Commons, случайные статьи — из публичного API русской Википедии. Избранное и настройки хранятся в localStorage браузера; между устройствами они не синхронизируются.

## Публикация на GitHub Pages

1. Открой Settings → Pages в репозитории.
2. В Build and deployment выбери Deploy from a branch.
3. Выбери ветку main и папку /(root), нажми Save.
4. После публикации сайт будет доступен по адресу GitHub Pages репозитория.

## Лицензии изображений

Wikimedia Commons содержит файлы с разными лицензиями и условиями. Сведения об авторе и лицензии показываются в окне изображения. Перед скачиванием и повторным использованием проверь страницу конкретного файла. Сам сайт не владеет изображениями.

## Примечания

- Для загрузки каталога и случайных статей нужно подключение к интернету.
- При недоступности внешнего API соответствующий раздел покажет сообщение об ошибке.
- Настройки и избранное принадлежат текущему браузеру и устройству.
