# WALLORA

Статическая галерея обоев, аватарок и случайных открытий из Википедии.

## Источники изображений

Поиск построен вокруг каталогов, где изображения изначально публикуются как обои или иллюстрации:

- **Wallhaven** — основной источник обоев для ПК и телефона. Запросы идут с фильтром SFW; можно искать по тегам, ориентации и типу композиции.
- **Waifu.im** — дополнительный источник аниме-иллюстраций. В запросах явно отключён NSFW-контент.
- **Wikimedia Commons** и **Openverse** — резервные открытые медиатеки. Они подключаются, когда специализированный каталог не возвращает результатов.

Wallhaven и Waifu.im не гарантируют свободную лицензию на каждое изображение. SFW означает фильтр по содержанию, а не разрешение на любое повторное использование. Для каждого файла показываются источник, автор и доступные сведения; перед публикацией или повторным использованием проверяй оригинальную страницу и лицензию.

## Разделы

- **Обои:** аниме, манга, цифровые иллюстрации, минимализм, игры, пиксель-арт, киберпанк, lo-fi, synthwave, ретро, тёмная эстетика, автомобили, космос, природа и абстракция.
- **Аватарки:** аниме, пиксель-арт, минимализм, фэнтези, животные и абстрактные иллюстрации.
- **Факты:** случайная статья из русской Википедии, краткое вступление, изображение при наличии и ссылка на оригинал.

## Интерфейс

- Поиск обоев по тегам и подгрузка следующих страниц.
- Фильтр ориентации и сортировка по разрешению, названию или случайному порядку.
- Просмотр изображения, автора, источника и лицензионной информации.
- Избранное хранится в localStorage.
- Тёмная, светлая и системная темы.
- Настройки частиц, анимаций и 3D-наклона карточек.
- Анимированная декоративная композиция в шапке вместо случайных стоковых фотографий.
- Адаптация для телефонов, планшетов и ПК.

## Технологии и хранение

Только HTML, CSS и JavaScript. Нет backend, платных API-ключей, сборщика или установки зависимостей. Поиск обращается к публичным API источников напрямую из браузера. Статьи загружаются через публичный API русской Википедии. Избранное и настройки хранятся только в текущем браузере и не синхронизируются между устройствами.

## Публикация на GitHub Pages

1. Открой Settings → Pages в репозитории.
2. В Build and deployment выбери Deploy from a branch.
3. Выбери ветку main и папку /(root), затем нажми Save.
4. Дождись завершения публикации GitHub Pages.

## Ограничения

Для каталога и случайных статей требуется подключение к интернету. Внешние источники могут менять доступность, структуру API или ограничения запросов. Если Wallhaven не возвращает результаты, сайт пытается получить резервную выдачу из Wikimedia Commons и Openverse. Доступность и количество изображений зависят от конкретного запроса. Локальные настройки и избранное не синхронизируются.
